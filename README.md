# FitSteps – Fitness Tracker

## Features
- Activity tracking (CRUD)
- Goal management (CRUD)
- Analytics dashboard
- Activity categorization

## Tech Stack
- FastAPI
- React (Vite)
- SQLite
- Axios

## Setup

Backend:
cd backend
uvicorn app.main:app --reload

Frontend:
cd frontend
npm install
npm run dev

## Environment

VITE_API_URL=http://localhost:8000
